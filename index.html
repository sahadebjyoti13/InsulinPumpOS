SETUP

Running in three steps

01

Download and unzip

Click the Download button above. Open the zip file — you'll find a folder called InsulinPumpOS inside. Move it somewhere convenient, like your Desktop.

02

Double-click install.bat

Open the folder and double-click install.bat. It handles everything — installs required components, sets up all databases and services, and opens the app automatically in your browser. No terminal. No configuration.

⚠ First run takes 5–10 minutes and may restart your computer once. After that, startup takes under 15 seconds.
03

Every day: start and stop

Double-click start.bat to launch the system each morning. Double-click stop.bat when done. Your data is always saved between sessions.

FEATURES

What the dashboard shows

📡

Live telemetry

Real-time RPM, position, mode, and status from the pump — updated every few seconds over MQTT.

🩸

CGM streaming

Continuous glucose values visualised as a scrolling chart with a 5-minute rolling window.

🍽️

Meal detection

The S** destabilisation index algorithm detects meal events from glucose dynamics — not just a threshold — and triggers a bolus prompt automatically.

🎛️

Remote control

Send power, reset, basal rate, and bolus commands directly from the browser — no physical access to the device needed.

📊

Historical data

Query any time range from InfluxDB. Plot any signal. Export raw data for clinical review.

🔒

Runs locally

Everything runs on your own computer. No patient data leaves your network. No cloud account required.
